# Foto Oku

Fotoğraftaki yazıyı okuyup (ML Kit OCR) yapay zeka sesiyle (Android TTS) sesli okuyan uygulama.
Okuma hızı kaydırıcıyla 0.5x – 2.0x arası ayarlanır.

## APK nasıl alınır
1. Bu klasörü GitHub'a yükleyin (main dalına).
2. Repo > Actions > "APK Derle" > çalışmasını bekleyin.
3. Bitince sayfanın altındaki Artifacts > FotoOku-APK dosyasını indirin, zip'ten çıkan app-debug.apk'yı telefona kurun.
